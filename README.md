# orca-pizhu 批注工具箱

虎鲸笔记（Orca Note）三合一工具箱插件：**批注、编辑器页签栏、回收站**。三个功能均可在插件设置中独立开关。

## 功能

### ① 批注
- **添加批注**：选中文字，点工具栏「添加批注」按钮，输入批注内容确认
- **波浪线标记**：批注文字带琥珀色波浪线 + 角标数字（块内序号，数字为天蓝色）
- **批注卡**：点击波浪线文字弹出批注卡，可编辑、删除（编辑框随文字内容自动伸缩高度）
- **汇总面板**：工具栏「批注面板」按钮在右侧打开面板，列出当前文档全部批注，点击跳转到所在块
- 批注数据全部存储在内联 fragment 中，跟随文本流，无独立数据文件，跨设备同步天然正确

### ② 编辑器页签栏
- 点击页签切换对应面板
- 中键点击 / 悬停「×」移出缓存
- 同面板内拖拽排序，拖到其他面板边缘即分栏（左/右/上/下），拖到中央替换
- 固定页签（📌）置顶、重启保留；垂直页签模式、宽度记忆
- 每面板可缓存多个编辑器，超出上限按最近使用淘汰

### ③ 回收站
- 删除页面自动存入回收站（普通搜索搜不到）
- 顶栏「回收站」入口可恢复或彻底删除，支持清空、按删除时间/剩余时长排序
- 超过保留天数自动清除快照

## 设置

| 项 | 默认 |
|---|---|
| 启用页签栏 | 开 |
| 垂直页签 / 每面板最大页签数 / 页签栏强调色 | 跟随所合并插件 |
| 启用回收站 | 开 |
| 回收站保留天数 | 30 |

> 页签栏与回收站功能分别提炼自 orca-tab-bar、orca-trash-bin。使用本插件时请**停用**这两个独立插件，避免功能重复。

## 安装

1. 将本目录放入虎鲸笔记的 `plugins` 目录（Windows: `C:\Users\<你>\Documents\orca\plugins`）
2. 重启虎鲸笔记，在设置中启用插件

## 开发

```bash
npm install
npm run build   # 产物在 dist/index.js
```

## 技术要点

- 入口：`src/main.tsx` 导出 `load/unload`，按设置开关调度各功能模块
- 批注：`src/renderer.tsx`（inline 渲染器 + 批注卡）、`src/commands.ts`（选区替换）、`src/ann.ts`（fragment 数据）、`src/panel.tsx`（汇总面板）
- 页签栏模块：`src/modules/tabbar.js`（原生 JS，`enable/disable` 接口）
- 回收站模块：`src/modules/trashbin.js`（原生 JS，`enable/disable` 接口；拦截 `delete-blocks`）
- 样式：`src/styles.ts` + `src/modules/*.css?inline`（经 `orca.themes.injectCSS` 注入）
